** Fonctions accessibles depuis Emacs

L'utilisateur n'a pas besoin de trouver / imaginer un nom de fichier,
ni un nom de répertoire : le script créé des noms temporaires et
l'utilisateur peut commencer à rédiger immédiatement.

Le répertoire et le fichier nouvellement créés sont ajoutés à l'index
des documents en cours (brouillons).

Une fonction simple permet de les renommer et de les déplacer.
 - option : nouveau projet (git)

Actions disponibles :

  - créer une note dans un espace brouillon
    - on se base sur l'arbo gitea ?
  - créer un projet qui réunit des notes (classeur)
  - déplacer une note
    - de l'espace brouillon vers un projet
    - d'un projet vers un autre projet
  - relire ses notes pour réviser : ouvrir un classeur et lire les notes
    - pouvoir modifier les notes
  - partager ses notes avec d'autres étudiants, des profs, sur le web
